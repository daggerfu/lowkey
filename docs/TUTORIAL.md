# lowkey: подробный туториал по всем функциям

lowkey — минималистичный браузер для macOS (AppKit + системный WebKit). Никаких вкладок
и постоянной адресной строки: каждый сохранённый сайт живёт в своём собственном окне
со своим собственным профилем. Этот туториал разбирает всё, что умеет lowkey, — от
первого запуска до автоматизации через CLI и диплинки.

---

## 1. Первый запуск и установка

1. Скачайте универсальный ZIP с [GitHub Releases](https://github.com/bobuk-io/lowkey/releases/latest),
   распакуйте и перенесите **lowkey.app** в `/Applications`.
2. Откройте приложение. **При запуске окна не открываются** — это нормально.
3. Нажмите на иконку в Dock ещё раз — появится адресная строка-приглашение (⌘L),
   либо откройте настройки через ⌘, и добавьте первый сайт.

Требования: macOS 10.15+, Intel/Apple Silicon, сборки подписаны Developer ID,
нотаризованы и прошиты (stapled). Автообновления нет: чтобы обновиться, закройте
lowkey, скачайте новый релиз и замените приложение. Настройки, история, профили
и входы в аккаунты сохраняются.

---

## 2. Главная идея: сайт = окно = профиль

- **Сохранённый сайт (saved site)** имеет короткий **алиас** (например `HA`),
  стартовый URL и свой собственный изолированный профиль WebKit
  (`WKWebsiteDataStore`, идентифицируется стабильным UUID).
- На каждый сайт — **одно живое окно**. Повторное открытие алиаса возвращает
  текущую страницу, даже если окно было скрыто.
- Позиция и размер окна запоминаются по UUID сайта; переименование алиаса
  **сохраняет** профиль и геометрию окна.
- **Обычные окна** (⌘N) делят между собой стандартное хранилище WebKit.
  Всплывающие окна делят профиль с окном, которое их открыло.
- Закрытие или скрытие окна **никогда не удаляет куки** и данные сайта.

## 3. Адресная строка и подсказки (⌘L)

- **⌘L** — приглашение ввода: URL, bare host (без схемы) или алиас.
  Bare host открывается по HTTPS, loopback — по HTTP. Поисковика нет:
  то, что не URL и не алиас, не откроется.
- Пустой запрос показывает только настроенные сайты.
- Подсказки берутся из алиасов и **последних 1000 уникальных введённых адресов**
  (не из всех посещённых страниц).
- Поддерживается перекладка русской/украинской и US-раскладки: `рф` найдёт `HA`.
  Сначала идут совпадения в исходном написании. Текст, который вы ввели,
  никогда не переписывается молча.
- Навигация — стрелками и Return. Наведите курсор на запись истории и нажмите **×**,
  чтобы забыть её; повторный ввод вернёт запись наверх.
- В окне сохранённого сайта сырой URL из ⌘L открывается в **новом обычном окне**;
  в обычном окне заменяет текущую страницу; **⌘Return** просит новое обычное окно.

### ⌘⇧L — «Open Location in This Profile…»

Загружает URL (или адрес алиаса) **в текущее же окно и профиль**, сохраняя куки
и состояние входа. Работает и во всплывающих окнах входа. Не переключает профиль
и не создаёт обычных окон, даже с ⌘Return. Явная навигация один раз обходит
политику внешних ссылок — полезно для OAuth-переадресаций, хотя Google и другие
провайдеры могут отклонять вход из встроенных браузеров.

## 4. Окна и клавиатура

| Сочетание | Действие |
|---|---|
| ⌘L | Адресная строка / алиас |
| ⌘⇧L | Открыть URL в текущем профиле |
| ⌘N | Новое обычное окно |
| ⌘← / ⌘→ | Назад / вперёд (кроме режима редактирования текста) |
| ⌘[ / ⌘] | Назад / вперёд — пункты меню |
| ⇧⌘H | Стартовая страница; начальный URL обычного окна |
| ⌘R | Перезагрузка; повтор неудавшегося адреса |
| ⌘W | Скрыть окно сайта / закрыть обычное окно |
| ⇧⌘W | Закрыть окно, сохранив профиль |
| ⌘, | Настройки |
| ⌘Q | Выйти из lowkey и остановить все страницы |

Особенности окон:

- Верхняя полоса окна — 20 pt, с акцентной линией 2 pt и кнопками
  «назад / старт / вперёд». Полосу можно таскать для перемещения окна.
- **⌘-клик** по левому контролу сайта закрывает окно; обычный клик — скрывает.
- Крестик сайта при зажатом ⌘ меняется на «Q»-глиф; у обычных окон «Q» по умолчанию.
- View → ⌃⌘F — системный полноэкранный режим.
- Обычные ссылки `target="_blank"` **не создают вкладок** (вкладок в lowkey нет вообще).

## 5. Настройки (⌘,)

Настройки разделены на три вкладки.

### Sites — сохранённые сайты

- **+** добавляет сайт: алиас, необязательный заголовок, стартовый URL.
- Под каждым сайтом показана его deep-link-ссылка вида `lowkey://HA/open`.
- **Политика внешних ссылок** («Links to other sites»):
  - *Open in the default browser* (по умолчанию);
  - *Open in lowkey*.
- **Extra origins** — дополнительные адреса, считающиеся «своими» для сайта:
  origin стартового URL (схема + хост + порт) всегда внутренний; поддомены —
  внешние, если не разрешены. Можно указывать маски вида `*.example.com`
  (при этом голый хост `example.com` в маску не входит).
- Неверные изменения не сохраняются, пока поля не исправлены
  («Changes to sites are saved when these are fixed»).

### Appearance — внешний вид

Пять режимов:

- **Tint** (по умолчанию): верхняя полоса окна окрашивается цветом страницы —
  сначала из мета-тега `theme-color`, затем из фона страницы (цвета с альфой
  ниже 0,9 не учитываются). Если цвета нет, полоса держит последний цвет,
  а до первого — цвет палитры. Смена цвета коротко анимируется.
- **Page**: фон по WebKit-фону страницы, `theme-color` как запасной вариант;
  палитра светлая/тёмная выбирается на окно.
- **System**: системная тема, когда страница не даёт пригодный цвет.
- **Light / Dark**: фиксированные палитры.

Светлая и тёмная палитры независимы, цвета панели и акцента редактируются.
Пресеты: Amber, Sage, Ocean, Terracotta, Dracula, Nord, Catppuccin, Gruvbox,
Solarized, Tokyo Night, One Light/Dark, Rosé Pine — либо «Custom».
Есть расширенный набор цветов («More colors») и предупреждения о низком
контрасте текста/акцента. lowkey **никогда не перекрашивает контент страницы**
и не навязывает ей CSS.

### History / General — история и файлы

- Показано число сохранённых записей ввода (максимум 1000) и кнопка
  **Clear History…** для очистки.
- Кнопка с путём открывает `~/.config/lowkey/config.json` в Finder.
- Ошибки чтения конфигурации показываются красным.

## 6. Профили, приватность и данные

- Конфигурация: `~/.config/lowkey/config.json`.
- История ввода: `~/Library/Application Support/Lowkey/history.json`
  (историческое написание каталога сохранено для совместимости).
- Аналитики, аккаунта приложения и бэкенда нет. Сайты видят обычный
  WebKit-трафик.
- Камера/микрофон запрашиваются по запросу сайта; загрузки и скачивания —
  нативные диалоги macOS. Accessibility/Input Monitoring не требуются.
- Удаление сайта в настройках (с подтверждением) **удаляет его профиль**
  вместе с сайтовыми данными.
- Скачивания, загрузки, JavaScript-диалоги и HTTP-аутентификация работают.
  Расширений и менеджеров паролей нет. lowkey не выдаёт себя за Safari,
  не отключает проверку сертификатов и не переносит чужие куки.

### Вход на сайты (sign-in)

- Окна входа делят профиль родительского окна и показывают хост провайдера.
- Попапы WebKit сохраняют поведение «открыватель/закрытие окна».
- Распознанная навигация провайдера может открыться отдельно и вернуть
  callback в окно сайта. Полноценная проверка на реальных провайдерах
  не завершена — учитывайте это.

## 7. Автоматизация: `lowkeyctl`

Хелпер лежит в `/Applications/lowkey.app/Contents/Helpers/lowkeyctl` и общается
с приложением через локальный IPC (не сеть). Удобно поставить ссылку в `PATH`
(см. [справку](https://bobuk.io/apps/lowkey/lowkeyctl/) — без sudo).

Синтаксис: `lowkeyctl <alias> <команда> …`. Алиас — регистронезависим.

### Оконные команды

| Команда | Действие |
|---|---|
| `toggle` | Показать/скрыть окно сайта; запускает приложение при необходимости |
| `open` | Создать или показать окно |
| `hide` | Скрыть окно (без запуска приложения) |
| `rewind` | Показать окно и вернуться к стартовому URL (не к предыдущей записи истории) |

### Команды страницы (требуют открытого окна на сохранённом origin;
работают в главном документе и открытых shadow roots, не в iframe)

| Команда | Действие |
|---|---|
| `status [--json]` | Видимость, фокус, минимизация, загрузка без подъёма окна |
| `inspect [--json]` | Список контролов: типы и метки (не значения полей) |
| `wait [label] [--timeout сек]` | Ждать готовности DOM; опционально — контрол с точной меткой. Таймаут 10 с по умолчанию, диапазон 1–300 |
| `click '<метка>'` | Клик по кнопке/ссылке по точной метке (регистрозависимо, пробелы нормализуются). Без совпадений, с несколькими совпадениями или по disabled — ошибка без клика |
| `fill '<метка>' '<текст>'` | Заполнить текстовое поле/textarea по метке (не пароли) |
| `select '<метка>' '<текст опции>'` | Выбрать опцию по видимому тексту в нативном single-select |
| `upload <файл> [--field '<метка>']` | Прикрепить файл (до 8 МиБ, один обычный файл) к file input; передаётся basename и байты, не локальный путь. По умолчанию требует ровно один input; `--field` выбирает по точной HTML/ARIA-метке. Заменяет выбор и шлёт `input`/`change`, форму не сабмитит |
| `save-pdf <путь.pdf>` | Сохранить весь текущий документ в A4-PDF (включая ниже вьюпорта, с print-стилями). Не перезаписывает существующий файл, не прокручивает lazy-контент |

Типичный цикл автоматизации:

```sh
ctl=/Applications/lowkey.app/Contents/Helpers/lowkeyctl
"$ctl" HA status --json
"$ctl" HA inspect --json
"$ctl" HA wait 'Refresh list' --timeout 30
"$ctl" HA click 'Refresh list'
"$ctl" HA fill 'Comment' 'Hello'
"$ctl" HA select 'Period' 'This month'
"$ctl" HA upload report.pdf
"$ctl" HA save-pdf ~/Desktop/page.pdf
```

Нюансы: `fill`/`select`/`upload` шлют input/change, но не submit — сайт может
реагировать своими обработчиками. Код выхода 0 у `click` означает лишь, что
клик отправлен, а не что сайт завершил действие. При неудаче не повторяйте
клик/загрузку автоматически. Также доступны **Save as PDF…** в контекстном меню
страницы и **View → Save as PDF…** (⌘⇧S) с диалогом сохранения.

## 8. Диплинки `lowkey://`

```sh
open 'lowkey://HA/open'      # создать или вернуть окно сайта
open 'lowkey://HA/toggle'    # frontmost → скрыть; иначе показать; неоткрытое → создать
open 'lowkey://*/toggle'     # если фокус у окна сайта — скрыть все; иначе поднять окна сайтов
open 'lowkey://HA/reload'
open 'lowkey://HA/back'
open 'lowkey://HA/forward'
open 'lowkey://HA/start'     # к стартовому URL
open 'lowkey://HA/hide'
open 'lowkey://HA/close'     # освободить живую страницу, профиль сохранить
open 'lowkey://'             # открыть приглашение ввода
```

- Имена регистронезависимы; неизвестные алиасы открываются в приглашении ввода.
- `lowkey://` ничего не знает про JavaScript, клики, шелл и автоматизацию страниц —
  для этого есть `lowkeyctl` (или Ting `lowkey`-step).

## 9. Файл конфигурации

Пример `~/.config/lowkey/config.json`:

```json
{
  "sites": [{
    "id": "B943B7D1-190E-43CB-AFAE-4058D93274E3",
    "alias": "HA",
    "title": "Home Assistant",
    "startURL": "https://homeassistant.local",
    "externalLinks": "defaultBrowser",
    "extraOrigins": ["https://ha.example.com", "*.nabu.casa"]
  }],
  "appearance": { "mode": "tint" }
}
```

Изолированный запуск с другим конфигом: `LOWKEY_CONFIG=/tmp/lowkey-test.json …`
(изолирует конфиг и историю ввода, но **не** дефолтное хранилище WebKit).

## 10. SOCKS-прокси

Сохранённые сайты могут открываться через именованный SOCKS-прокси. Список
прокси и правила задаются в `~/.config/lowkey/config.json`, а в Настройках
(вкладка Sites, поле Proxy) прокси выбирается для конкретного сайта.

```json
{
  "proxies": [{
    "name": "tor",
    "host": "127.0.0.1",
    "port": 9050,
    "username": "необязательно",
    "password": "необязательно"
  }],
  "proxyDomains": [{ "proxy": "tor", "hosts": ["example.com", "*.onion"] }],
  "sites": [{ "alias": "HA", "startURL": "https://homeassistant.local", "proxy": "tor" }]
}
```

- Сайт с полем `"proxy": "tor"` **всегда** открывается через этот прокси.
- `proxyDomains` маршрутизирует сохранённые сайты, чей стартовый хост
  совпал с правилом: `example.com` — хост и поддомены, `*.example.com` —
  только поддомены. Явная привязка сайта к прокси важнее правила.
- Прокси применяется к окнам сайта, открытым **после** сохранения конфига;
  уже открытые окна остаются на старом профиле. Окна входа и попапы идут
  через тот же прокси, что и сайт.
- Обычные окна (⌘N) маршрутизировать нельзя — они делят стандартное
  хранилище WebKit, а у него нет прокси на окно.
- У WKWebView нет публичного API прокси: lowkey применяет конфигурацию через
  закрытый интерфейс WebKit, когда ОС его предоставляет. На системах без него
  сайт откроется **без прокси** (в Настройках это отмечено), а в лог пишется
  предупреждение.
- Логин/пароль передаются для SOCKS5; без них используется SOCKS4. Невалидные
  порты, неизвестные имена и т.п. блокируют сохранение конфига — ошибки видны
  в Настройках.

## 11. Чего в lowkey нет (и не будет обмана в ожиданиях)

- Нет вкладок, расширений, менеджера паролей, Sparkle-обновлений и Homebrew-каски.
- Нет поисковой строки/поисковика-по-умолчанию.
- Нет аналитики, аккаунтов и бэкенда.
- Нет автоматического ухода редиректов и script-навигации наружу (чтобы не ломать вход).

## 12. Удаление lowkey

1. Если нужно стереть данные сайтов — удалите сохранённые сайты в настройках
   (это удалит их профили).
2. Выйдите из lowkey и удалите lowkey.app.
3. Конфиг и история останутся по путям из раздела 6 — при желании удалите их вручную.
   Удаление приложения само по себе не стирает данные WebKit, включая обычный профиль.
